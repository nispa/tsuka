# Procedura di Traduzione

## Obiettivo
Tradurre i file Markdown dalla cartella `work-disk/` alla cartella `work-disk-it/` dall'inglese all'italiano.

## Regole di Trasformazione
1. **Approccio Granulare**: Leggere un blocco $\to$ Tradurre il blocco $\to$ Accumulare la traduzione.
2. **Preservazione Asset**: Non tradurre i riferimenti alle immagini (es. `![alt](assets/path)`).
3. **Pulizia Codice**: Rimuovere tutti i commenti di pagina stile `<!-- page x -->`.
4. **Mantenimento Struttura**: Preservare interamente la struttura Markdown, le tabelle HTML e i link.
5. **Output**: Scrivere il file finale in `work-disk-it/` con lo stesso nome dell'originale.
